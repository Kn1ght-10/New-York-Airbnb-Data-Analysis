**Exploratory data analysis of NYC Airbnb listings — pricing, availability, and neighborhood dynamics across the five boroughs.**

## 🔎 Questions explored

- 💰 **Pricing** — how listing prices distribute and vary by borough and neighborhood
- 🏠 **Room types** — entire homes vs. private/shared rooms, and their price premiums
- 🗺️ **Geography** — where listings cluster, and which neighborhoods command the highest rates
- 📅 **Availability & reviews** — activity patterns that separate high-traffic listings from dormant ones
- 👤 **Hosts** — multi-listing host behavior
